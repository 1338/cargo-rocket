# API reference

[← README](../README.md)

All routes are relative to your instance's base URL. JSON request bodies use `Content-Type: application/json`. Application errors use `{"error":"message"}`; malformed JSON and extraction errors from Axum can return plain text.

## Authentication

- **Admin token:** the server's `ADMIN_TOKEN`, used for configuration and the dashboard.
- **Project API key:** generated when creating a project, used for upload requests and private file access.
- **Upload token:** included in an issued upload URL; it authorizes one raw PUT without an additional Authorization header.

Admin and project API requests use `Authorization: Bearer <token>`. Keep project keys on your application server. Browsers should receive only the upload URL. Only hashes of API keys and upload tokens are persisted. Admin authentication also compares hashes; the configured admin secret remains in the process environment.

## Request an upload

`POST /api/uploads` · Project API key · **201 Created**

```json
{"filename":"photo.png","content_type":"image/png","size":12345}
```

| Field | Rules |
|---|---|
| `filename` | 1–255 bytes; no slashes, backslashes, or control characters; stored as metadata |
| `content_type` | Exact MIME declaration such as `image/png`; no parameters or wildcard; must match the project's allowlist if configured |
| `size` | Integer byte count, including zero; must not exceed the project's maximum |

Example response (IDs and token abbreviated):

```json
{
  "id":"file-uuid",
  "key":"project-uuid/file-uuid",
  "upload_url":"https://cargo.example.com/upload/file-uuid?token=opaque-token",
  "method":"PUT",
  "headers":{"Content-Type":"image/png"},
  "expires_at":1793276100,
  "file_url":"https://cargo.example.com/api/files/file-uuid/content"
}
```

`expires_at` is a Unix timestamp in seconds. Persist `id` in your application; storage keys are generated by Cargo Rocket, never by the caller. `file_url` is private and requires the project key.

## Upload bytes

`PUT /upload/{id}?token=...` · URL token · **200 OK**

Send the raw file body, not multipart form data. Use the exact returned Content-Type. If Content-Length is supplied, it must match the declared size. Chunked HTTP transfer is accepted; the total byte count is still enforced.

```json
{"id":"file-uuid","key":"project-uuid/file-uuid","status":"complete"}
```

A URL expires after 15 minutes. Authentication and header validation happen before claiming it. After a transfer starts, the grant is consumed even if the transfer fails. Request a new URL after any failed or uncertain transfer; use file metadata to check whether an earlier request completed. Concurrent attempts to use a URL cannot both claim it.

## Metadata

`GET /api/files/{id}` · Owning project key · **200 OK**

```json
{
  "id":"file-uuid",
  "project_id":"project-uuid",
  "backend_id":"backend-uuid",
  "key":"project-uuid/file-uuid",
  "filename":"photo.png",
  "content_type":"image/png",
  "size":12345,
  "expires_at":1793276100,
  "status":"complete",
  "created_at":1793275200
}
```

Statuses: `pending`, `uploading`, `complete`, `failed`, and `expired`. Expired pending grants are reported as expired when read; no scheduled job is needed. Metadata for another project's file returns 404.

## Download

`GET /api/files/{id}/content` · Owning project key · **200 OK**

Streams a completed object as an attachment with `application/octet-stream`. The download filename is its file ID; the original filename and declared type remain available in metadata. Incomplete files return 409. Public download URLs, range requests, and download presigning are not implemented.

## Manage storage

`GET /api/admin/backends` · Admin token · **200 OK**

Returns an array of saved connections. Responses contain environment variable **names**, not resolved credential values.

`POST /api/admin/backends` · Admin token · **201 Created**

```json
{
  "name":"Local files",
  "kind":"fs",
  "options":{"root":"/srv/cargo-rocket/files"},
  "secrets":{}
}
```

Returns the configuration with a generated `id`. Kinds are `fs`, `s3`, `azblob`, `ftp`, and `sftp`; see [storage configuration](storage.md). Saving validates configuration and constructs the adapter but does not prove connectivity. Connections are immutable.

`POST /api/admin/backends/{id}/test` · Admin token · **200 OK**

Writes a uniquely named probe, reads it back, then deletes it. Returns `{"ok":true}` on success. The operation permits 20 seconds for write/read and another 10 for cleanup. Failed probes may require manual cleanup when storage is unavailable.

## Manage projects

`GET /api/admin/projects` · Admin token · **200 OK**

Returns an array of `id`, `name`, `backend_id`, `max_size`, and `allowed_types`. Keys and key hashes are never returned.

`POST /api/admin/projects` · Admin token · **201 Created**

```json
{
  "name":"Customer portal",
  "backend_id":"backend-uuid",
  "max_size":104857600,
  "allowed_types":["image/png","image/jpeg","application/pdf"]
}
```

`name` and `backend_id` are required. `max_size` defaults to 100 MiB and must be between one byte and 10 GiB. `allowed_types` defaults to an empty array, allowing any valid MIME declaration. Projects are immutable in this version; create a new project for another destination or policy.

```json
{"id":"project-uuid","api_key":"one-time-secret"}
```

`POST /api/admin/projects/{id}/rotate-key` · Admin token · **200 OK**

No request body required. Returns `{"api_key":"new-one-time-secret"}`. The previous project key stops working immediately, including for downloads. Previously issued upload URLs remain usable until consumed or expired. Files remain assigned to the same project.

## Recent uploads and health

- `GET /api/admin/uploads` (admin token) returns the latest 100 upload records across projects, newest first, in the metadata format above. No pagination or filtering yet.
- `GET /health` (no token) returns `{"status":"ok"}`. This is process liveness, not a remote-storage readiness check.

## Status codes

| Code | Meaning |
|---|---|
| 400 | Invalid input, MIME type, filename, or mismatched declared length |
| 401 | Missing or invalid admin/project key |
| 403 | Invalid upload URL token |
| 404 | Unknown resource or file owned by a different project |
| 408 | Upload exceeded the five-minute transfer timeout |
| 409 | Upload URL already claimed, or requested file is incomplete |
| 410 | Upload grant expired |
| 413 | File exceeds the project limit or received body exceeds declared size |
| 500 | Internal database/configuration failure |
| 502 | Storage operation failed |
| 503 | All 16 upload slots are occupied; retry shortly |
| 504 | Storage connection test or probe cleanup timed out |

JSON control-plane bodies are limited to 32 KiB. Raw uploads use the project size limit instead.
